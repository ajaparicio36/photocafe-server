# Triage labels

| Canonical role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | More information is required |
| ready-for-agent | ready-for-agent | Fully specified for autonomous implementation |
| ready-for-human | ready-for-human | Human implementation is required |
| wontfix | wontfix | Will not be actioned |

When a skill applies a triage role, update the issue's `Status:` to the matching value. Use `State:` exclusively for the wayfinding lifecycle values described in `issue-tracker.md`.
